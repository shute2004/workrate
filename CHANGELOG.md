# Changelog

All notable changes to Workrate will be documented here.

## 0.1.0 - 2026-09-16

Initial public release.

- Multiple independent concurrent timers
- USD hourly-rate configuration
- Live elapsed time and earnings
- USD/JPY conversion with hourly refresh and cached fallback
- Local state persistence across app restarts
- macOS menu bar integration
- DMG packaging for macOS
- Low-background-work timer architecture
