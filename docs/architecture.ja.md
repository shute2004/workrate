# アーキテクチャ

[English](architecture.md) | **日本語**

Workrate は、React / TypeScript フロントエンドと Rust バックエンドで構成された、macOS 向けの Tauri 2 アプリケーションです。

## 設計目標

1. アイドル時・バックグラウンド時のリソース使用量を小さくする
2. アプリ終了後や Mac 再起動後でもタイマー状態を復元できるようにする
3. ユーザーの作業データをローカルに保持する
4. 個人用タイマーに不要なインフラを持ち込まない

## タイマーモデル

各タイマーは以下を保持します。

- `id`
- `name`
- `hourlyRateUsd`
- `accumulatedSeconds`
- `isRunning`
- `startedAt`

停止中の経過時間は `accumulatedSeconds` です。

実行中は次の値から経過時間を求めます。

```text
accumulatedSeconds + (now - startedAt)
```

バックエンドには、タイマー状態を1秒ごとに増加させる interval はありません。このため、Workrate を終了していた時間や Mac がスリープしていた時間も、実行中のタイマーであれば次回起動時に自然に復元できます。

時給を変更しても経過時間は変わりません。収益は、現在設定されている時給と現在の経過時間から都度算出します。

## フロントエンド

React フロントエンドは、UI と表示用の派生値を担当します。

ウィンドウが表示されフォーカスされている間だけ、`useVisibleClock` が1秒ごとに表示用の現在時刻を更新します。ウィンドウが非表示になったりフォーカスを失ったりすると interval は停止します。

この1秒 interval はタイマー状態そのものではなく、再描画を発生させるためだけのものです。経過時間は毎回、永続化されたタイマーデータから再計算します。

## Rust バックエンド

永続化される状態の変更はバックエンドが担当します。

- タイマー作成・編集・削除
- 開始・停止
- リセット
- 為替レート更新

`model.rs` には Tauri に依存しない状態遷移を置いており、ユニットテストの対象にしています。

## 永続化

状態は Tauri の application data ディレクトリに JSON として保存します。

書き込み時は一時ファイルへ保存してから rename することで、通常の書き込み中断によって不完全な JSON ファイルが残りにくいようにしています。

状態保存は1秒ごとではなく、タイマー操作などの変更時だけ行います。

## 為替レート

Workrate は ExchangeRate-API の USD 基準レートを取得し、その中の JPY レートを利用します。

保存済みレートが古い場合はアプリ起動時に更新し、その後は1時間ごとに更新します。

取得に失敗しても、最後に取得した正常なレートは消去しません。

## ウィンドウとメニューバー

macOS のメインウィンドウを閉じても、プロセス自体は終了せずウィンドウだけを非表示にします。

メニューバーの Workrate アイコンから、ウィンドウを再表示・フォーカスできます。メニューバーの **終了** を選択するとアプリを終了します。

これにより、Workrate を邪魔にならない状態にしつつ、不要なタイマー更新処理を動かさずに実行状態を維持できます。

## リリース

Tauri で、Workrate.app と Applications フォルダへのショートカットを含む macOS DMG を生成します。

バージョンタグを push すると GitHub Actions が Apple Silicon / Intel 両対応の Universal Binary をビルドし、DMG を GitHub Release に添付します。
